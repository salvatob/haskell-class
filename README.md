# haskell-class
This is a repository for a class NPRG068 at MFF UK.

During the course, we did three projects:
1. A small graphical application, where the user can move, rotate or flip several tiles.
2. A two level parser for a Python-like language.
3. A client-server app, that uses the front end from assignment 1 to distribute the info to a server via web sockets.
